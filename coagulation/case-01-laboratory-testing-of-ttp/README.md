# Case 1: Laboratory Testing of TTP

An interactive educational module for pathology residents covering the laboratory evaluation of thrombotic thrombocytopenic purpura (TTP).

## Module features

- Continuous single-page educational layout
- Responsive sidebar navigation
- PLASMIC score calculator
- Preanalytical specimen activity
- ADAMTS13 assay comparison
- Interactive disease-mechanism walkthrough
- Branching clinical case
- Knowledge-check quiz with immediate explanations
- Progress saved locally in the learner's browser

## Files

```text
case-1-ttp-testing/
├── index.html
├── styles.css
├── script.js
├── README.md
└── assets/
```

The module uses plain HTML, CSS, and JavaScript with no frameworks, package manager, build process, or external dependencies.

## Preview locally

Open `index.html` directly in a browser. A local web server may also be used, but is not required.

## Deploy with GitHub Pages

1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Commit the files to the default branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the default branch and the `/ (root)` folder, then save.

GitHub will display the public site URL after deployment completes.

## Educational scope

This module is intended for resident education. It does not replace institutional laboratory procedures, clinical judgment, or patient-specific medical decision-making.
